## 💻 Problems Practiced

### 1. Linear Search

Search for a specific element by checking array elements one by one.

```text
Array: 10 20 30 40 50
Target: 30

Result: Element found at index 2
```

### 2. Largest in Array

Find the maximum element present in an array.

```text
Array: 10 45 23 67 12

Largest = 67
```

### 3. Binary Search

Search for an element efficiently in a **sorted array** by repeatedly dividing the search space into half.

```text
Array: 10 20 30 40 50
Target: 40

Result: Element found
```

### 4. Reverse an Array

Reverse the order of elements.

```text
Before:
10 20 30 40 50

After:
50 40 30 20 10
```

### 5. Pairs in Array

Print all possible pairs of elements from an array.

```text
Array:
1 2 3

Pairs:
(1,2)
(1,3)
(2,3)
```

### 6. Print Subarrays

Print all possible contiguous subarrays.

For:

```text
1 2 3
```

Subarrays include:

```text
1
1 2
1 2 3
2
2 3
3
```

## ⏱️ Basic Complexity

| Problem / Algorithm | Time Complexity |
|---|---:|
| Array Traversal | O(n) |
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Find Largest Element | O(n) |
| Reverse Array | O(n) |
| Print Pairs | O(n²) |
| Print Subarrays | O(n³)* |

> *Printing the contents of every subarray requires O(n³) time with the straightforward nested-loop approach because there are O(n²) subarrays and printing each one can take O(n) time.

## 📖 Key Learnings

- Arrays allow multiple values of the same data type to be stored under one variable.
- Java arrays use **zero-based indexing**.
- Array elements can be accessed using their index.
- Arrays can be passed directly to methods.
- Linear Search can be used without sorting the array.
- Binary Search requires a sorted array.
- Two-pointer techniques can be useful for reversing arrays.
- Nested loops are commonly used for pair and subarray problems.
- Time and space complexity help evaluate algorithm efficiency.
