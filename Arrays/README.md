## 🔍 Searching Algorithms

### 1. Linear Search

- Sequential searching
- Searching an unsorted array
- Finding the position of an element
- Time Complexity: **O(n)**

### 2. Binary Search

- Searching in a sorted array
- Divide-and-conquer approach
- Finding the middle element
- Time Complexity: **O(log n)**

---

## 🔃 Sorting Algorithms

### 1. Selection Sort

- Find the minimum element
- Place it at the correct position
- Time Complexity: **O(n²)**

### 2. Bubble Sort

- Compare adjacent elements
- Swap elements when required
- Repeatedly move the largest element toward the end
- Time Complexity: **O(n²)**

### 3. Insertion Sort

- Build the sorted portion of the array
- Insert each element into its correct position
- Time Complexity: **O(n²)**

### 4. Counting Sort

- Count occurrences of elements
- Use frequency information to construct the sorted array
- Suitable for a limited range of integer values
- Time Complexity: **O(n + k)**

# ⏱️ Algorithm Complexity

| Algorithm | Best Case | Average Case | Worst Case |
|---|---:|---:|---:|
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Counting Sort | O(n + k) | O(n + k) | O(n + k) |

> `n` = number of elements  
> `k` = range of values in Counting Sort

# 🧠 Searching vs Sorting

### Searching

Searching is the process of finding a particular element in a data structure.

Example:

```text
Array: 10 20 30 40 50

Search: 30

Result: Element found at index 2
```

### Sorting

Sorting means arranging elements in a particular order.

Example:

```text
Before:
5 2 8 1 3

After:
1 2 3 5 8
```

# 📖 Key Learnings

- Arrays store multiple values of the same data type.
- Array indexing starts from `0` in Java.
- Arrays have a fixed size once created.
- Array elements are stored in contiguous memory locations conceptually from the data-structure perspective.
- Arrays can be passed to methods.
- Linear Search can work on unsorted arrays.
- Binary Search requires a sorted array.
- Selection, Bubble, and Insertion Sort generally have **O(n²)** worst-case complexity.
- Counting Sort can be efficient when the range of values is limited.
- Understanding searching and sorting is important for coding interviews.
