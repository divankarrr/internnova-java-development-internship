# 📅 Day 04 – Conditional Statements in Java

## 📌 Overview

On Day 04 of my **Java Development Internship at Internnova**, I learned how Java makes decisions using conditional statements. These statements allow a program to execute different blocks of code based on whether a condition evaluates to `true` or `false`. I also explored the ternary operator and the `switch` statement by implementing practical examples.

- Implement `if`, `if-else`, and `else-if` statements.
- Solve problems using nested conditions.
- Use the ternary operator for concise conditional expressions.
- Learn the `switch` statement for multiple-choice decisions.
- Build simple real-world programs using conditional statements.
