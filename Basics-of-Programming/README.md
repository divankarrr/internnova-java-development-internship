# 📅 Day 01 – Java Fundamentals

## 📌 Overview

Today, I began my Java Development Internship by learning the fundamentals of programming logic and Java. The session covered problem-solving techniques using flowcharts and pseudocode, Java syntax, variables, data types, input/output operations, conditional statements, and operators.

---

## 🎯 Learning Objectives

- Understand algorithmic thinking using flowcharts and pseudocode.
- Learn the structure of a Java program.
- Understand how Java code is compiled and executed.
- Work with variables and different data types.
- Perform input and output operations.
- Implement decision-making using conditional statements.
- Use various operators in Java.
