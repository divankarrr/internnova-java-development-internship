## Question 4

What will be the **type of the result** in the following Java code?

**Hint:** Look at the largest data type involved in the expression.

```java
byte b = 4;
char c = 'a';
short s = 512;

int i = 1000;
float f = 3.14f;
double d = 99.9954;

double result = (f * b) + (i % c) - (d * s);
```
