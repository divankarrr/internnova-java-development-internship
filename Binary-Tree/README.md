## 🌳 What is a Binary Tree?

A **Binary Tree** is a tree data structure in which each node can have at most two children: a left child and a right child.

Example:

```text
        1
       / \
      2   3
     / \
    4   5
````

---

## 🔄 Tree Traversals

### Preorder Traversal

```text
Root → Left → Right
```

### Inorder Traversal

```text
Left → Root → Right
```

### Postorder Traversal

```text
Left → Right → Root
```

### Level Order Traversal

Visits nodes level by level using a **Queue**.

## 💡 Key Takeaways

1. A Binary Tree has at most two children per node.
2. Tree problems are commonly solved using recursion.
3. Preorder, Inorder, Postorder, and Level Order are important tree traversals.
4. Level Order Traversal uses a Queue.
5. The height of a tree represents its maximum depth.
6. The diameter represents the longest path between two nodes.
7. Lowest Common Ancestor is useful for solving distance-related problems.
8. HashMap and Queue can be used for problems such as Top View.
9. Understanding tree traversal is essential for solving advanced DSA problems.
