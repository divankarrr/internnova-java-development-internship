## 🧠 What is Dynamic Programming?

**Dynamic Programming (DP)** is a problem-solving technique used when a problem can be divided into smaller subproblems and their results can be reused.

DP mainly focuses on:

- Breaking a problem into smaller subproblems
- Storing results of already solved subproblems
- Avoiding repeated calculations
- Improving time complexity

## 🔹 Ways of Dynamic Programming

The two major approaches covered are:

### 1. Memoization

Memoization uses **recursion + storage**.

Previously calculated results are stored so that the same subproblem does not need to be solved again.

### 2. Tabulation

Tabulation uses an iterative approach.

The solution is built from smaller subproblems using a **DP table**.

## 🪜 Climbing Stairs

The Climbing Stairs problem is used to understand the basic concept of Dynamic Programming.

It can be solved using:

- Recursion
- Memoization
- Tabulation

The DP approach avoids repeatedly calculating the same subproblems.

## 🎒 0-1 Knapsack

In the **0-1 Knapsack** problem, each item can either be:

- Selected
- Not selected

The problem can be solved using:

- Recursion
- Memoization
- Tabulation

## 🎯 Target Sum Subset

The Target Sum Subset problem determines whether a subset of the given elements can produce a required target sum.

Dynamic Programming can be used to store the results of previously solved subproblems.

## ♾️ Unbounded Knapsack

In **Unbounded Knapsack**, an item can be selected multiple times.

This differs from 0-1 Knapsack, where each item can be selected at most once.

## 🪙 Coin Change

The Coin Change problem deals with finding ways to make a particular amount using given coin denominations.

Dynamic Programming helps avoid solving the same combinations repeatedly.

## 🪵 Rod Cutting

The Rod Cutting problem involves dividing a rod into pieces to maximize the total obtainable value.

DP can be used to calculate the optimal result efficiently.

## 🔤 Longest Common Subsequence (LCS)

The **Longest Common Subsequence** problem finds the longest subsequence common to two strings.

It was studied using:

- Recursion
- Memoization
- Tabulation

## 🔡 Longest Common Substring

The Longest Common Substring problem finds the longest sequence of characters that occurs continuously in both strings.

## 📈 Longest Increasing Subsequence

The **Longest Increasing Subsequence (LIS)** problem finds the longest subsequence in which the elements are in increasing order.

## ✏️ Edit Distance

Edit Distance determines the minimum number of operations required to convert one string into another.

Operations can include:

- Insert
- Delete
- Replace

## 🔄 String Conversion

Dynamic Programming can also be applied to string conversion problems by breaking the conversion into smaller subproblems.
