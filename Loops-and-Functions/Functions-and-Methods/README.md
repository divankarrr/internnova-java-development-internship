# 📅 Day 06 – Functions & Methods in Java

## 📖 Key Learnings

- Methods help divide a program into smaller reusable components.
- Parameters allow data to be passed into methods.
- Arguments are the actual values passed during a method call.
- Java uses **Call by Value** for passing arguments.
- Each method call creates a new stack frame in the Call Stack.
- Variables have a specific scope depending on where they are declared.
- Variables declared inside a block cannot be accessed outside that block.
- Method overloading allows multiple methods to have the same name with different parameter lists.
- Methods can simplify complex mathematical and logical problems.
