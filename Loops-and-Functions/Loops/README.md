# 📅 Day 05 – Loops in Java

## 📌 Overview

This module covers the fundamentals of **loops and iteration in Java**. Loops are used to execute a block of code repeatedly, making programs shorter, more efficient, and easier to manage.

The module also introduces `break` and `continue` statements for controlling the flow of loops and uses loops to solve common programming problems such as number printing, pattern printing, reversing numbers, and checking whether a number is prime.

---

## 🎯 Learning Objectives

- Understand the need for loops in programming.
- Learn how `while`, `for`, and `do-while` loops work.
- Understand the flow of execution inside loops.
- Print numbers using different looping techniques.
- Calculate the sum of the first N natural numbers.
- Generate square patterns using nested loops.
- Reverse a given number.
- Understand the use of `break` and `continue`.
- Check whether a number is prime using loops.

## 📖 Key Learnings

- Loops help execute repetitive tasks efficiently.
- A `while` loop checks the condition before execution.
- A `for` loop is useful when the number of iterations is known.
- A `do-while` loop executes its body at least once.
- `break` immediately terminates a loop.
- `continue` skips the current iteration.
- Nested loops can be used to create patterns.
- Loops can be used to solve mathematical and logical problems.
