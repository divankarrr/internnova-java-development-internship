# 📅 Day 05 – Nested Loops & Pattern Printing

## 📌 Overview

On Day 05 of my **Java Development Internship at Internnova**, I learned about **nested loops** and their application in pattern printing.

Nested loops allow one loop to execute inside another loop. They are particularly useful for solving problems involving rows and columns, such as star patterns, pyramids, and character-based patterns.

---

- Understand the concept of nested loops.
- Learn how outer and inner loops work together.
- Understand row and column-based execution.
- Create different patterns using nested loops.
- Develop logical thinking and problem-solving skills.
