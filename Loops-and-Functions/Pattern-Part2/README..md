# 📅 Day 07 – Advanced Pattern Printing in Java

## 📌 Overview

On Day 07 of my **Java Development Internship at Internnova**, I continued working with **nested loops and pattern printing** by solving intermediate and advanced pattern problems.

## 🧠 Pattern-Solving Approach

For every pattern, the following approach is used:

```text
1. Identify the number of rows
        ↓
2. Identify spaces in each row
        ↓
3. Identify stars/numbers in each row
        ↓
4. Create the outer loop
        ↓
5. Create inner loops for spaces
        ↓
6. Create inner loops for stars/numbers
        ↓
7. Move to the next row
```
