## 💻 Core Concepts Covered
*   **Java Syntax**: Standard structure of a Java program, main method, and printing output.
*   **Variables & Data Types**: Declaring and initializing primitive types (`int`, `double`, `char`, `boolean`) and reference types (`String`).
*   **User Input**: Utilizing the `Scanner` class to capture keyboard inputs.
*   **Operators**: Working with arithmetic, relational, logical, and assignment operators.
*   **Type Casting**: Implementing both implicit (widening) and explicit (narrowing) data conversions.
